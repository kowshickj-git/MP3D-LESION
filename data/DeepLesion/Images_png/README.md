# data/DeepLesion/Images_png

The extracted CT slices, `Images_png/<study>/<slice>.png`, made from `../zips/`
by `python tools/prepare_deeplesion.py --root data/DeepLesion`.
`run_project.bat` puts here only the slices the web app's built-in samples need
(`DeepLesion_sample_slices.zip` on the v1.0 release).
