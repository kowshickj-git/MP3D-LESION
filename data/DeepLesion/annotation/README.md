# data/DeepLesion/annotation

COCO-style DeepLesion annotations: `deeplesion_{train,val,test}.json` from
MVP-Net and the `deeplesion_{train,val,test}_local.json` subsets for parts
01-04. They come in `DeepLesion_annotation.zip` on the v1.0 release, extracted
into `data/DeepLesion/` (see `../README.md`).
