What this detects

MP3D finds lesions — the abnormalities a radiologist would bookmark and measure on a CT slice. It is a single-class detector: every box it draws is just “lesion”. It does not name a disease, does not separate benign from malignant, and does not predict which organ a finding sits in.

The eight regions below are how DeepLesion labels its ground truth, so each page gives you real cases from that part of the body to test against. Each page also carries one lesion-free slice from the same anatomy as a negative control.

What this system does here

For every slice it builds a 9-slice stack, runs the detector, and returns each finding with a confidence, a long and short axis in millimetres, and a size band. Where a radiologist bookmark exists it also reports the overlap, so you can see whether a box is a real hit or a false alarm.
